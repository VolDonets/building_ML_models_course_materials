State-of-the-art object detection datasets (You can use it, but it's too heavy for basic computers)

1. [COCO dataset](https://www.tensorflow.org/datasets/catalog/coco_captions) -- this one large (you can pick up only a few classes here) ~ 80 object categories
2. [FLIC](https://www.tensorflow.org/datasets/catalog/flic) -- people detection dataset from movies
3. [KITTI](https://www.tensorflow.org/datasets/catalog/kitti) -- autonomous driving dataset
4. [OPEN IMAGES v4](https://www.tensorflow.org/datasets/catalog/open_images_v4) -- 600 object categories, this one extremely large (you can pick up only a few classes here)
5. [PASCAL VOC](https://www.tensorflow.org/datasets/catalog/voc) -- 20 object categories
6. [WiderFace](https://www.tensorflow.org/datasets/catalog/wider_face) -- face detection dataset
